100KB-Array is a flexible float array memory module.

Description:
Stores, reads, and writes float values with audio-rate indexing, optional file save/load, and list I/O.
Pins:

Input Array / Output Array – List in/out
Input / Output – Audio value in/out
Index In / Index Out – Array position
Array Size – Resize
Write / Clear – Control writing and clearing
Use File? / File Name – Optional disk persistence

Usage:
Ideal for wavetables, sequencers, sample storage, or any patch that needs indexed float memory.
