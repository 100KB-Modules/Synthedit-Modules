100KB-MathEv is a real-time mathematical expression evaluator capable of parsing complex formulas.

Description:
This module evaluates a string-based mathematical expression at the sample rate. It supports built-in functions, constants, user-defined variables, and variable assignment, making it a powerful tool for advanced modulation and signal processing.

Modes:
Mode 0 – Math
Standard mathematical mode. Input signals (X, Y, Z, T) are passed directly to the expression as double-precision values.

Mode 1 – SynthEdit (SE)
Optimized for SynthEdit environments. Inputs are scaled by 10.0 to match a 0–10V range, and the final result is scaled down by 10.0 before outputting.

Pins:
X, Y, Z, T – Audio/Control inputs (mapped to variables x, y, z, and t in the formula)
Expression – String input containing the mathematical formula (e.g., sin(x * pi) + y)
Mode – Integer (0 = Math, 1 = SynthEdit)
Result – Audio output containing the evaluated result

Mathematical Capabilities:

Operators: +, -, *, /, % (modulo), ^ (exponentiation), ( ) (parentheses)
Built-in Constants: pi, e
Built-in Functions:
Trig: sin, cos, tan, asin, acos, atan, atan2
Hyperbolic: sinh, cosh, tanh
Log/Exp: exp, log, log10, pow, sqrt
Arithmetic: floor, ceil, fabs, fmod, hypot, sign, min, max, nroot
Conversion: rad2deg, deg2rad
Special: ldexp, frexp, modf
Variable Assignment: Supports assigning values to custom variables (e.g., a = x + y) for use later in the same expression.
Environment Variables: Access system environment variables by prefixing the name with an underscore (e.g., _MY_VAR).
Usage:
Ideal for creating complex LFO shapes, custom waveshaping, advanced modulation routing, and generating algorithmic signal patterns.

Note: The expression parser is case-insensitive. Variable names are limited to 16 characters.
