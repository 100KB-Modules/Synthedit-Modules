Smooth is a signal smoother with controllable smooth time.

Description:
This module smoothly transitions between input values, preventing clicks and zipper noise. Perfect for creating natural portamento/glide on pitch signals or smoothing any modulation.


Pins:

Input – Signal to be smoothed (e.g. pitch CV or modulation)
Smooth Rate – Controls the smoothing time (expressed as Pitch). Higher values = faster smoothing.
Output – Smoothed signal

Usage:
Ideal for portamento, glide effects, and cleaning up knob or automation movements.
Smooth Rate ≤ 0 bypasses the smoothing (instant passthrough).
